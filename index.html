Installing VICIdial on a Hostinger VPS

VICIdial installation on Hostinger KVM 2 Your setup is suitable for a small VICIdial deployment, provided you confirm the VPS resources and call capacity.Your installation configuration VPS Hostinger KVM 2 Current OS Ubuntu 24.04 Agents 5–10 Calling Inbound + outbound Installation Fresh server Recommended approach Install VICIdial using ViciBox rather than trying to install the entire VICIdial stack directly on Ubuntu 24.04. Important: Do not run random VICIdial installation scripts on your Ubuntu server. VICIdial has specific operating-system and dependency requirements. ViciBox provides a more consistent installation environment. 1. Important Hostinger limitation I checked Hostinger's current documentation. There is an important issue: Installation blocker Hostinger does not currently allow customers to upload their own operating-system images to its VPS platform. Hostinger +1 This means you cannot simply mount the official ViciBox ISO and boot your KVM 2 VPS from it. The official ViciBox stable release is version 12.0.2. It installs the complete OpenSUSE-based VICIdial environment. ViciBox +1 My recommendation: Don't erase Ubuntu or attempt an improvised installation yet. First, decide whether to keep Hostinger or move to a VPS provider that supports custom ISO installation. 2. Recommended architecture For your 5–10 agents, use a single-server VICIdial installation. VICIdial single-server architecture Agents (5–10) Browser-based agent interface VICIdial web server Agent interface and administration MariaDB database Campaigns, users, calls and reports Asterisk telephony server Inbound calls, outbound calls and recordings SIP Trunk Provider Telephone network connectivity The official ViciBox Express installation puts all three server roles on one machine and is intended for contact centers with fewer than 20 agents. ViciBox 12.0 documentation 3. Installation procedure if you use a compatible VPS Once you have a server that supports ViciBox ISO booting, follow these steps. Step 1 – Download ViciBox Official download: Download ViciBox installation ISO Choose: ViciBox_V12.x86_64-12.0.2.iso Step 2 – Install the operating system Attach the ISO to your VPS. Boot into the ISO. Select Install ViciBox Server. Configure your timezone, hostname, network and root password. Complete the installation and reboot. Step 3 – Install VICIdial Log in through SSH as root and run: bash vicibox-express Confirm the installation when prompted. After installation: bash reboot Step 4 – Verify services After reboot, connect through SSH: bash screen -ls Then check Asterisk: bash asterisk -r Type quit to exit the Asterisk console. Step 5 – Access VICIdial Open: text http://YOUR_SERVER_IP/vicidial/admin.php The initial administrator credentials documented by ViciBox are: text Username: 6666 Password: 1234 Change the default password immediately. ViciBox 12.0 documentation Step 6 – Configure your call center Inside VICIdial, configure: Admin users and agent accounts. Inbound and outbound campaigns. SIP trunk provider. Inbound DID routing. Outbound caller ID. Agent extensions and softphones. Call recording. Timezones and dialing permissions. Step 7 – Test calling Test the following before allowing agents to work: Inbound calls reach the correct campaign. Agents can answer calls. Outbound calls connect successfully. Two-way audio works. Recordings are saved. Call reports are generated. Manual VICIdial installation on Hostinger KVM 2 We'll keep your existing Hostinger VPS and investigate a manual installation. One important technical issue: VICIdial wasn't designed as a standard Ubuntu 24.04 application. Its installation process depends on particular versions of Asterisk, PHP, database components, web-server configuration and operating-system packages. For that reason, I recommend a controlled installation rather than running an all-in-one installation script that could leave your VPS in an inconsistent state. Our target architecture is: Hostinger KVM 2 – Ubuntu 24.04. VICIdial – call center management. Asterisk – telephony engine. MariaDB – database. Apache/PHP – web interface. 5–10 agents. Inbound and outbound calling through an authorized SIP trunk. 1. Before installing anything First, connect to your VPS using SSH. From Windows, you can use PowerShell: bash ssh root@YOUR_SERVER_IP Check the server specifications: bash cat /etc/os-release bash nproc free -h df -h Check your public IP: bash curl -4 https://icanhazip.com Check whether anything is already listening on important ports: bash ss -tulpn Do not install Asterisk, MariaDB or VICIdial yet. We should first establish compatibility and avoid conflicting dependencies. 2. What the official documentation tells us The official VICIdial documentation lists Asterisk, MySQL/MariaDB, Apache, PHP and Perl as required components. It also provides a manual installation procedure. vicidial.org +1 However, the available Ubuntu installation guide is very old, so it should not be treated as a validated Ubuntu 24.04 installation procedure. GitHub I would therefore use a staged approach: Prepare and secure Ubuntu. Verify compatible versions of the VICIdial components. Build a test installation. Validate the agent interface and telephony. Only then consider production deployment. 3. Prepare Ubuntu 24.04 First, take a Hostinger VPS snapshot if that option is available. Update the operating system: bash apt update apt upgrade -y apt install -y curl wget git unzip \ nano vim screen htop chrony \ build-essential pkg-config Set the server hostname. Replace the example with your own domain: bash hostnamectl set-hostname pbx.yourdomain.com Check the hostname: bash hostnamectl Check time synchronization: bash timedatectl status Enable the time synchronization service: bash systemctl enable --now chrony 4. Prepare your domain I recommend using a dedicated subdomain. For example: Purpose Domain VICIdial pbx.yourdomain.com Agent interface pbx.yourdomain.com Administrator pbx.yourdomain.com In your DNS provider, create an A record: text Type: A Name: pbx Value: YOUR_HOSTINGER_VPS_IP Check DNS resolution: bash getent hosts pbx.yourdomain.com Do not expose the administrator interface publicly without access restrictions. 5. Verify server resources Run: bash free -h bash df -h bash lscpu bash lsblk For your 5–10 agents, I would aim for: At least 8 GB RAM. 2 or more vCPUs. SSD storage with sufficient recording capacity. Reliable network connectivity. If your VPS has limited CPU or memory, simultaneous calls and recording may affect performance.
